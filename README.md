## Условие задачи
Вычислить значение функции F(x, y) по заданной формуле. Значения констант и контрольные значения указаны в таблице.
Формула:
F(x, y) = (cos^3(y) + 2^(x*d)) / (e^y + ln(sin^2(x) + 7.4))
Значения констант:
d = 1
Контроль:
F(-3, 2.7 * 10^-3) = 0.374139
F(2, 1 * 10^-3, 10) = 1.86 * 10^-5

   - **x** — аргумент функции.

   - **d** — константа.
   - **F** — результат вычисления.
3. Задать значения констант и переменных.
4. Вычислить значение функции по формуле.
5. Вывести результат на экран.

## 2. Реализация программы

```c
#include <stdio.h>
#include <math.h>

int main()
{
    double x, y, d, F;

    d = 1.0;
    
    // Первый контроль из таблицы
    x = -3.0;
    y = 2.7 * pow(10, -3);

    // Вся формула в одну строку
    F = (pow(cos(y), 3) + pow(2, x * d)) / (exp(y) + log(pow(sin(x), 2) + 7.4));

    printf("F(-3, 2.7e-3) = %lf\n", F);

    // Второй контроль из таблицы
    x = 2.0;
    y = 10.0;

    F = (pow(cos(y), 3) + pow(2, x * d)) / (exp(y) + log(pow(sin(x), 2) + 7.4));

    printf("F(2, 10) = %le\n", F);

    return 0;
}
```
